# POWER large-system architecture catalog

This branch owns the complete pinned modern POWER architecture catalog and comparative notes. It is inventory/research; no executable Idriç POWER backend is claimed.

A future direct backend may be opened only after an explicit reproducible assembler/linker/execution gate and a tiny exact source/oracle surface. Server POWER remains separate from automotive Power e200/VLE/SPE.

Complete architecture knowledge does not imply required, emitted, or tested support.
